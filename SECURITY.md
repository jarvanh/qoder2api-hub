# Security policy

Please report suspected vulnerabilities privately to [zhang8586201314@gmail.com](mailto:zhang8586201314@gmail.com). Do not post details, credentials, or reproductions in public issues, pull requests, or discussions. You may also use GitHub’s private reporting form under **Security → Report a vulnerability**.

Include the affected version or commit, a description of the impact, and any redacted evidence. Do not send real account tokens or passwords. Please state your preferred credit and any requested disclosure timeline. The maintainers will coordinate triage, disclosure, and any advisory or identifier request with the reporter. A report does not need to be public before a fix is ready.
