# v1.9.0 路由性能

## 可重复基准

```bash
python scripts/benchmark_routing.py --reference b16b5c8 --output logs/tests/routing-performance-v190.json
```

Windows 11、项目内置 Python 3.12.14，1000个合成账号、60层，500次选号解析×7轮，取每次解析中位数：**0.9789 ms → 0.0925 ms（10.58×）**。所有数据均为临时假账号，不发上游请求。该结果仅说明路由配置解析开销降低，不代表上游TTFT或网络耗时降低。

## 改动

- 配置以设备号、inode、大小、mtime_ns、ctime_ns验证缓存；同版本运行时复用解析后的规则和层，不再每个请求读取文件、hash、JSON反序列化。
- 公共管理接口仍返回独立副本；缓存至多16个配置路径，策略选号状态上限512组。
- 原子保存立即失效；外部编辑、原子替换、删除和重建通过文件指纹失效，畸形配置失败关闭。
- Windows的stat(path).ctime与fstat.ctime含义存在差异；通过读后路径/句柄一致性核对避免永久缓存不命中。
- 新增缓存热命中无文件读取、管理副本隔离、外部修改/损坏/替换/删除回归。

v1.8.0已有的长历史、SSE拷贝路径、单次编码和统计缓存优化保留，本版不再把它们重复计为新增收益。
